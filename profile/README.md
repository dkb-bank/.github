# Open Source. Gemeinsam weiterentwickeln.

Digitale Lösungen entstehen gemeinsam. Open-Source-Projekte machen Wissen und Software zugänglich und schaffen Grundlagen, auf denen viele aufbauen können. Deshalb unterstützen wir Open-Source-Projekte mit Spenden.

## Warum wir Open Source unterstützen

Hinter guter Open-Source-Software stehen Menschen und Communities, die Ideen teilen und Lösungen gemeinsam weiterentwickeln. Mit unseren Spenden unterstützen wir die Arbeit dieser Menschen und Communities.

## Wen wir unterstützen

- [k9s](https://github.com/derailed/k9s)
- [Serenity BDD](https://github.com/serenity-bdd)
- [Apache Software Foundation](https://www.apache.org/)
- [Vue.js](https://github.com/vuejs/)
- [Nuxt](https://github.com/nuxt/nuxt)
- [The Linux Foundation](https://www.linuxfoundation.org/) und die [Cloud Native Computing Foundation (CNCF)](https://www.cncf.io/)
- [OpenTofu](https://github.com/opentofu)
